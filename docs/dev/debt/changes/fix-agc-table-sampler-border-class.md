# libSceAgcDriver

## change - [Table S#s]
- [Table S#s](../../../core/libs/prx/libSceAgcDriver/Graphics/src/ShaderResources.cpp) that clamp to transparent black use an extra Vulkan sampler per distinct entry for integer image views, in the classic sampler table binding and in GPU heap stages, where it takes a global sampler heap slot after the table's samplers. A selected opaque-white entry faults because packed formats and integer depth views need format-specific border conversion. Entries using Vulkan clamp-to-border also fault when a guest axis needs half-border or mirrored-border coordinate handling, or, outside GPU heap stages, their sampler variants exceed device capacity. With `APS5_BINDLESS_IMAGES=1` the [bindless resolver](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BindlessResolvers.cpp) still rejects every table S# with a border. Device image table images never sample through a table S#; such columns stay on the GPU heap stage's CPU image table.
