# libSceAgcDriver

## add Functional

- [Compute pipelines are journaled when their build starts](../../../core/libs/prx/libSceAgcDriver/Execution/src/VulkanDevice.cpp) (libSceAgcDriver) - `VulkanDevice::computePipeline` records a compute pipeline in the pipeline journal before the driver call, so a build the run does not finish (the process is killed or crashes during a long compile, or the build throws) is built again by the next run's journal replay at start-up. Grand Theft Auto VI (PPSA38500) ends its load with its own watchdog after about 30 s without progress while the NVIDIA 620.73.04 compiler builds compute pipelines of 185,121 and 578,062 SPIR-V words; recorded only after the build, they were never journaled and every run compiled them again at the same point. A build that fails every time is retried by every replay and counted as failed there. A pipeline that crashes the driver's compiler now crashes the next run during its start-up replay as well as where the title first dispatches it; `APS5_NO_PIPELINE_JOURNAL=1` or deleting `pipelines.journal` avoids that.
