# libSceAgcDriver

## add Opt-in draw paths

- [Device image table](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DeviceImageTable.cpp) (`APS5_GPU_PATH`) - opt-in, takes effect only with `APS5_GPU_HEAP` on a device with VK_EXT_descriptor_heap. A draw whose expected images the table cannot take (a T# the CPU cannot evaluate before the draw is recorded, more than 16 candidates for one use, a full table or a heap past its margin) is still recorded with its device columns: a selected image that is not resolved yet reads zeros in that batch and is resolved from the miss ring for the next. Only later draws of the program take the CPU table map; a dispatch is recorded again at once. Recording the same draw again through the CPU map is not implemented.
- [Device image keys beside the bindless image keys](../../../core/libs/prx/libSceAgcDriver/Graphics/src/DeviceImageKeys.cpp) (`APS5_GPU_PATH`, `APS5_BINDLESS_IMAGES`) - the device image table and the bindless image heap each keep their own key table, miss ring and table ABI (`DeviceImageKeys` and `DeviceImageTableAbi` for `APS5_GPU_PATH`, `BindlessImageKeys` and `BindlessImageTableAbi` for `APS5_BINDLESS_IMAGES`). Both started from the same key table and have since drifted apart; they are not merged. They never run together: with `APS5_BINDLESS_IMAGES=1` the GPU heap stays off, and the device image table takes its slots from the GPU heap.
